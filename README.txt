# MIYAD Electronics Shop

## Files
- `index.html` — website structure
- `style.css` — Premium Black & Green design
- `script.js` — search, category filters, cart and WhatsApp ordering
- `products.js` — product names, prices, categories, colors and image paths
- `images/` — put your own product photos here

## Run locally
Open `index.html` in a browser. An internet connection is needed for Google Fonts and the sample online product photos.

## Update products
Edit `products.js`. To use your own image:
1. Put the image in `images/`, e.g. `images/my-led.jpg`.
2. Set the product's `image` value to `"images/my-led.jpg"`.
3. Change the product's `name`, `price`, `category`, `colors`, etc.
4. Save and upload the changed files to GitHub.

## GitHub Pages
Upload all files and the `images` folder to the repository root. In GitHub:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## WhatsApp
The order link is configured for 01957835577 (`8801957835577`). Customers must press Send in WhatsApp to submit the message.

## Important
This is a static website. Product updates require editing `products.js` and uploading the changes to GitHub. The cart is stored in each visitor's browser. There is no server-side order database or payment gateway. Sample product prices and image links are placeholders; replace them with your actual products and prices before publishing.
